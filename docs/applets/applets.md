### Version Control and Diffs

Aegraph graphs are meant to be used as both data and code. They represent functional entities in the Aegraph ecosystem. Aegraph is a calculator for objects. It offers Version Control and Diff Tooling mechanisms.

- meld-equivalent highlighting of differences between graphs A and B
- file management tools for connecting to version systems like git
